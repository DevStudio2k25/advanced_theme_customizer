# Contributing

Thanks for your interest in improving Advanced Theme Customizer.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Add or update tests for your changes.
4. Open a pull request with a clear summary.

## Contribution license terms

By submitting a contribution (including pull requests, patches, or code snippets),
you agree that project maintainers may use, modify, and distribute your
contribution under the project license in LICENSE and any future license chosen
for this project.

## Important policy

This project allows use and internal modification, but does not allow
redistribution or republishing without written permission from maintainers.
