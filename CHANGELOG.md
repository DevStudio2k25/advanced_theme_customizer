## 0.1.0

- Implemented advanced customization core with scoped style models.
- Added deterministic resolver with state fallback and trace support.
- Added JSON profile codec with schema v1 to v2 migration path.
- Added validation safeguards and structured runtime diagnostics.
- Added draft workflow with apply, discard, and bounded undo semantics.
- Added persistence adapter with in-memory store implementation.
- Added component registry metadata with page, group, and component descriptors.
- Added built-in customization panel with scope, component, state, and action controls.
- Added panel hooks for skin, strings, and section visibility.
- Added integration launchers for settings mode and per-page mode.
- Added unsaved-change guard flow for safe panel exits.
- Added preview bridge widgets for live preview and in-page preview badge.
- Added sample host app in `example/`.
- Added unit and widget tests for resolver, import/export, migration, diagnostics, preview, and panel workflows.
